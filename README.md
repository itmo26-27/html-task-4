# HTML-задание 4. Шашки с анимацией

Задание к лекции по CSS-анимациям. [Условие на слайдах](https://itmo-frontend-lectures.vercel.app/1-sem/html/8-animations/index.html#/8)

Откройте `index.html` в браузере. В шаблоне уже есть доска 8 × 8, стили и начальная расстановка. Превратите её в игру для двух игроков за одним компьютером.

## Ход шашки

Реализуйте выбор шашки и перемещение на свободную клетку по правилам игры. Обрабатывайте клики на шашках и клетках через делегирование событий на доске. Шашка должна плавно перемещаться на новую позицию с помощью CSS `transition`.

## Взятие

Когда игрок перепрыгивает через шашку соперника, запустите анимацию взятия через CSS `@keyframes`. Можно уменьшить шашку или плавно сделать её прозрачной. Удалите её из DOM после окончания анимации.

## Победа

Когда у соперника закончились шашки, создайте через JavaScript элемент с сообщением о победе. Укажите, кто выиграл.

## Самопроверка

- Выберите шашку и сходите на свободную клетку. Проверьте логику хода и плавность перемещения.
- Перепрыгните через шашку соперника. Проверьте, что анимация видна целиком, после чего фигура исчезает из DOM.
- Возьмите последнюю шашку соперника. Проверьте имя победителя и создание уведомления через DOM API.
- Убедитесь, что по коду легко проследить обработку хода, взятия и победы.

По желанию добавьте подсветку выбранной шашки и доступных клеток, звуки или дамок.
